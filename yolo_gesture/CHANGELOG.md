# 变更记录

## 0.2.1 — 2026-11-01

- 取景框从 11x9 放大到 **13x11 格**（现场反馈太小），上板确认裕度仍充足；
- 串口输出补 CR（原来只有 LF，Windows 控制台上每行叠加成一片）；
- 固件 UART 写入统一处理：`uart_putc` 遇换行先发回车。

## 0.2.0 — 2026-11-01

- 独立成子项目：代码、数据、模型、脚本、文档都收进 yolo_gesture/；
- 路径集中到 paths.py，不再各自算仓库根；
- 每个工具都支持 --help，默认值与 Makefile 一致；
- 新增 make test（模型 + 跟踪器，不需要硬件）与 make repro（训练→打包→校验→编译）。

### 修复（上板过程中发现）

- **输入未量化**：0..255 的字节直接喂 INT8 引擎，>127 变负数，三个手势分数完全一样；
- **推理序列重复**：相机固件里有一份拷贝，与已验证的那份不一致；现在只有 rps_forward 一处；
- **裕度恒为 0**：找次优分的循环从 best=0 起、先与自己比较，第 0 类获胜时裕度算成 0，门限永不通过 → 显示值卡住；
- **取景框错位 40 px**：竖直偏移写成 80，正确是 120；
- **剪刀永远 weak**：该类通道标准差仅 0.8，裕度天生约 6，门限从 8 改为 4。
